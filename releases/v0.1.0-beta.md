# v0.1.0-beta

Released 2026-10-26

First public beta of the Nocleye API Gateway.

## Release notes

- **Routing:** longest-prefix matching for servers and routes, path rewriting (remove a pattern, add a prefix), and HTTPS backends with a custom CA.
- **Request control:**
  - Header rules: allowlist, remove, set, preserve `Host`.
  - Client ID rules: IP, token, header or query string.
  - Usage control: rate limits at global, server or route level, in `Cascade` or `Strict` mode.
- **Authentication:** JWT in `Bearer` or `RawHeader` mode, with HS256, HS384, HS512, RS256, ES256 and EdDSA.
- **Operations:**
  - `nocleye check` validates a config before you deploy it.
  - Swap the live config, or try a testing config, on a running gateway.
  - Support server with health probes and a testing proxy.
  - TLS termination and trusted proxies.
- **Observability:** gateway log, JSON access log and Prometheus metrics.
- **Platforms:** Linux and macOS on x86-64 and ARM64, plus a Docker image.

Docs for these features: [servers and routes](https://nocleye.com/docs/servers-and-routes/), [header rules](https://nocleye.com/docs/header-rules/), [client ID rules](https://nocleye.com/docs/client-id-rules/), [usage control](https://nocleye.com/docs/usage-control/), [authentication](https://nocleye.com/docs/authentication/), [CLI](https://nocleye.com/docs/cli/), [support server](https://nocleye.com/docs/support-server/), [observability](https://nocleye.com/docs/observability/).

# v0.4.0-beta

Released 2026-11-08

OAuth2, token introspection and JWE authentication, scope rules, and a stricter rate limit caller identification.

## Release notes

- **Breaking:** client id collection changed. The default IP detection rule was removed, and any client id rule other than IP is now used as caller id. A config that relied on the implicit IP default must add an explicit IP rule or set `IfMissingUseIP`.
- **New auth modes:**
  - `OAuth2`: validates tokens against the identity provider's JWKS.
  - `OAuth2Introspection`: validates opaque tokens through the identity provider's introspection endpoint.
  - `JWE`: encrypted tokens read from a header, with an optional signed JWT inside (`NestedSigningMethod`).
- **Scopes:** `RequiredScopes` can be set on `GlobalConfig`, servers and routes, so one auth method can be defined once and reused with different scopes.
- **Signing methods:** `Bearer` and `RawHeader` now accept `RS384`, `RS512`, `PS256`, `PS384`, `PS512`, `ES384` and `ES512`.
- **Rate limit:**
  - New flag to control burst.
  - New `IfMissingUseIP` flag on client id rules. The IP fallback is now applied only when you ask for it.
  - A request whose client id can't be collected is refused with 401 and a missing identification value error, in all modes.
- **Fixes:**
  - Fix rate limit burst control.
  - Fix `cascade` and `strict` rate limit modes, which now enforce id availability.
  - The config parser rejects misconfigured rate limit rules, and client id rules without at least one mode.
  - Fix reading the `custom` and `apiKey` query string steps.
  - Fix the CLI message and list of available signing methods, and remove misleading auth option texts.
- **Config check:** `nocleye check` reports every new OAuth2, scope, JWE and introspection rule with where it is and how to fix it. It also reports an invalid burst value and a rate limit defined without a way to identify the callers. It opens the JWKS URL of every OAuth2 auth method and reports it if it is unreachable or has no usable keys; use `--offline` to skip this.
- **Metrics:** new Prometheus metrics `gw_jwks_fetch_total`, `gw_jwks_unknown_kid_refetch_total`, `gw_jwks_keys_age_seconds` and `gw_introspection_total`.
